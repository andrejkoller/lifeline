# lifeline

Personal portfolio website — a timeline component of my life, work, and projects. Built with Next.js, TypeScript, and Tailwind CSS.

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- [Lucide](https://lucide.dev) icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
